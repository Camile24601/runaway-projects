# Chinese Weekly Report Format

Use concise Chinese. Put essence before detail.

## Compact Digest

```markdown
**本周最值得看**
1. 名称: 一句话精华。
   信号: 官方发布/星标增长/重要 release/与你的 skill 体系匹配。
   你可能会用在: 具体工作流。

2. ...

**我建议先追**
先看 X，因为它最可能立刻改善你的 Y 工作流。

**可追问方向**
- 深挖 X 的实现思路
- 判断 X 是否值得做成 skill
- 帮我试跑/安装/读源码
- 只看 OpenAI/Anthropic 官方更新
```

## Deep Dive On Request

When the user asks for details, expand one item with:

- 核心概念
- 为什么现在重要
- 关键源码/文档位置
- 最小可验证实验
- 是否值得沉淀为 skill
- 风险: 安全、维护、许可、生态成熟度
- 下一步建议

## Tone

Be direct and useful. Do not write a long newsletter unless asked. Avoid English except project names and necessary technical terms.
