# 生成程序校验清单

## 写代码前

- 已列出逻辑说明中的全部 Sheet 及用途。
- 已列出各输入文件、Sheet、表头行和必需字段。
- 已明确输出工作簿、目标 Sheet、写入行为和模板保留项。
- 已明确应生成或修改的每份 `.py` 及执行顺序。
- 已向用户提交完整确认稿，并获得用户明确同意生成代码。
- 已向用户确认 `business_section`；SAP 登录相关脚本也已确认 `login_section`。
- 如包含 SAP 下载，已默认纳入 `01-公司期间选择.py`，或已记录用户明确跳过的原因。
- 如第一步包含备份，已确认备份目录、目标期间及重复运行是否覆盖旧备份。
- 金额、税率、期间、匹配优先级和异常处置没有未标注的猜测。

## 代码级验证

- 为每份生成/修改的程序运行 `python -m py_compile <file.py>`。
- 核对变量引用、函数名称、输入文件前缀、Sheet 名及输出路径。
- 检查编码字段是否误删前导零或被 Excel 转为科学计数。
- 检查日期、期间、百分比、金额的类型与写入格式。
- 多步骤程序的交接文件、字段名和编号一致。
- 期间选择程序保留 `Enter`/数字键盘 `Enter` 提交与经确认的数据备份行为。

## 样例结果验证

样例与口径齐全时，至少验证：

- 各关键输入字段存在，标题行读取正确。
- 过滤后的行数与业务示例可以解释。
- 高/中/无匹配等分级数量及未匹配清单可查看。
- 金额、税额、数量或控制总额按照确认规则核对。
- 当期重复运行不会错误叠加历史数据。
- 多 Sheet 写回位置、表头、公式、格式和汇总引用正确。

## 交付声明

明确区分：

- `语法已验证`：只代表代码可编译。
- `样例已运行`：代表使用所给样例执行通过。
- `业务结果已核对`：仅在用户确认口径并核对关键结果后声明。
- `真实系统步骤已验证`：仅在实际 SAP、OA 或 Excel 运行环境测试完成后声明。
