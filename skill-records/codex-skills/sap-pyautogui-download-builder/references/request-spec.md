## 必须确认的易错项

- `凭证编号`、`供应商编码` 等编码字段是否可去掉前导零。
- “前缀为 01 的表”是指哪个目录；若该目录可能有多个 `01*` 文件，应说明选择规则。
- 上游 Excel 是否在本脚本运行前已存在。
- 多项选择图标是否在执行键盘操作后获得焦点。
- 导出是否使用通用 `save_excel()`，或有特殊 SAP 保存流程。
- 布局名称、布局归属：优先明确到输出条目如 `ZMM020_1`，其次才按 TCode 统一配置。
- 公司范围是否涉及 KUS/AWS/GROUP；若包含集团或 8400/8500，必须确认系统、账号字段和是否拆成多轮下载。
- 分批下载是否需要写入文件名批次、系统来源，并同步给后续数据库导入脚本。
- SAP 导出保存后是否会自动打开 Excel；若会，默认使用母版的“仅关闭本次新增 Excel 进程”策略。
- 凡需要 SAP 下载的完整项目，默认需要 `01-公司期间选择.py`；若不生成，需要说明参数与备份由哪一步完成。
- 凡需要生成 `02-SAP数据下载*.py`，默认也要生成或保留匹配的 `01-公司期间选择.py`，且二者 `business_section` 必须一致。
- `business_section` 必须在生成前由用户确认；不得自行命名后直接生成完整代码。
- 期间选择母版默认保留普通 `Enter` 与数字键盘 `Enter` 的确认提交绑定、密码框 `******` 脱敏显示，以及缺失配置文件自动初始化。
